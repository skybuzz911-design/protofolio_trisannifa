# Portfolio Trisanifa Ramadani

Website portofolio pribadi untuk tugas sekolah.

## Profil
- **Nama:** Trisanifa Ramadani
- **Umur:** 17 tahun
- **Kelas:** XI TJKT 2
- **Hobi:** Main bola dan main PS
- **Bidang:** Teknik Jaringan Komputer dan Telekomunikasi

## Teknologi
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3 via CDN
- Google Fonts

## Fitur
- Responsive design untuk mobile, tablet, dan desktop
- Dark mode dengan JavaScript dan localStorage
- Filter project berdasarkan kategori
- Smooth scrolling
- Tombol kembali ke atas
- Navbar responsive Bootstrap

## Cara Menjalankan
1. Download atau clone repository.
2. Buka `index.html` di browser.
3. Pastikan koneksi internet tersedia agar Bootstrap dan Google Fonts dari CDN dapat dimuat.

## Deploy ke GitHub Pages
1. Buat repository GitHub, misalnya `portfolio-trisanifa`.
2. Upload seluruh isi folder project ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save**.
7. Tunggu proses deployment selesai.
8. Link demo akan tersedia dengan format:
   `https://USERNAME.github.io/portfolio-trisanifa/`

> Ganti `USERNAME` dengan username GitHub milik kamu.
